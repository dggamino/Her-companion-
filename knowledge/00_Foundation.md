# HER-KB-000 — Fundación del Proyecto

## Propósito

Este documento constituye el punto de partida oficial de HER Companion™.

Su objetivo es preservar el contexto esencial del proyecto para evitar pérdida de continuidad entre sesiones de trabajo, modelos de IA, dispositivos o limitaciones de contexto.

A partir de esta versión, este documento se considera la referencia histórica canónica del proyecto.

---

# Origen

HER Companion™ no nació como un repositorio de software.

El proyecto comenzó como un proceso iterativo de exploración mediante conversaciones con modelos de lenguaje.

Durante su fase inicial el conocimiento fue distribuido entre múltiples sesiones de conversación.

Debido a las limitaciones de contexto de las herramientas de IA, surgió la necesidad de crear una Base de Conocimiento persistente y versionada.

---

# Problema identificado

Las conversaciones con IA presentan limitaciones inherentes:

- contexto limitado;
- sesiones independientes;
- pérdida de continuidad;
- dificultad para mantener trazabilidad;
- dependencia excesiva de la memoria conversacional.

Como consecuencia, el conocimiento estratégico podía fragmentarse o perderse.

---

# Decisión Fundacional

Se adopta Git como sistema de preservación del conocimiento.

La Base de Conocimiento pasa a ser la única fuente oficial del proyecto.

Las conversaciones dejan de ser la fuente de verdad y pasan a ser herramientas temporales para producir nuevo conocimiento.

# Principio de Continuidad

Toda conversación futura debe entenderse únicamente como una herramienta de trabajo.

El conocimiento oficial únicamente existe cuando ha sido incorporado a esta Base de Conocimiento mediante control de versiones.

---

# Regla Fundamental

Si existe una discrepancia entre una conversación y la Base de Conocimiento:

La Base de Conocimiento prevalece.

---

# Protocolo para iniciar una nueva sesión

Toda nueva sesión debe comenzar revisando:

1. HER-KB-000 Fundación del Proyecto
2. Working_On
3. Decisiones
4. Preguntas Abiertas

Solo después debe iniciarse nuevo trabajo.

---

# Objetivo del laboratorio

Construir un sistema de conocimiento trazable, evolutivo y verificable que permita desarrollar HER Companion™ sin depender de la memoria conversacional de ninguna herramienta de IA.
